# 涂白车（tree-whitewash-robot）

基于 STM32F103C8T6 的树木涂白小车。采用**非阻塞状态机**架构，摄像头/AI 视觉流程与蓝牙急停**共用一路串口 USART2**——无论正在执行什么动作，蓝牙一收到 `T` 就立即停止。

## 特性

- **非阻塞架构**：所有动作（舵机平滑运动、超声波测距、电机运行）都用 1ms 时间戳推进，不用 `Delay_ms` 死等，主循环始终能响应串口指令。
- **`T` 急停 / `G` 恢复**：`T` 拥有最高优先级，任何状态下立即停所有执行器并锁定；`G` 恢复自动。
- **舵机平滑运动**：三次 Hermite（smoothstep）缓起缓停，非阻塞推进。
- **超声波非阻塞测距**：触发后靠时间戳判断，带无回波超时处理。
- **升降位置跟踪**：底端限位开关 + 上电自动找零，断电重启也能恢复正确位置。
- **电池电压检测 + 欠压保护**：PA4 分压采样（12V 锂电池 = 3 串），滑动平均滤波 + 迟滞，欠压 9.0V 自动停并报警。
- **独立看门狗（IWDG）**：程序跑飞/卡死时硬件自动复位兜底（约 2.5s 超时），不占用任何引脚。
- **串口通信超时保护**：非等待状态 120 秒收不到指令，自动停所有执行器并回安全等待态（防 AI 流程中断后车一直空转）。
- **复位原因记录**：开机显示复位原因（看门狗 / 软件 / 上电 / NRST 引脚），方便排查意外重启。

## 接线表

| 外设 | 引脚 | 类型 | 说明 |
|---|---|---|---|
| 蓝牙 / 摄像头串口（USART2） | PA2 = TX，PA3 = RX | UART | AI 流程字符 + 蓝牙 `T`/`G` 共用一路 |
| 舵机 1（喷头臂） | PB10 | PWM（TIM2_CH3，全重映射） | 3 线舵机 0~180°，0.5~2.5ms |
| 舵机 2 | PB11 | PWM（TIM2_CH4，全重映射） | 3 线舵机 0~180° |
| 超声波 HC-SR04 | PB3 = Trig（出），PB4 = Echo（入） | GPIO + EXTI4 | 接近测距，需开 SWJ JTAG 关闭 |
| 驱动轮电机 1（左） | PB12/PB13 方向 + PA6 = PWM | 直流电机 | PA6 = TIM3_CH1 |
| 驱动轮电机 2（右） | PA8/PA9 方向 + PA7 = PWM | 直流电机 | PA7 = TIM3_CH2 |
| 升降电机 | PB5/PB6 方向 + PB0 = PWM | 直流电机 | PB0 = TIM3_CH3 |
| 升降底端限位开关 | PB7 | 输入（内部上拉） | 一端接 PB7，一端接 GND，压下导通；上电自动找零 |
| 电池电压检测 | PA4 | ADC 输入（ADC_IN4） | 分压电阻 100k/33k，12V 锂电池（3S），欠压 9.0V 保护 |
| 水泵 | PA0 | 输出 | 高电平开水泵 |
| 蜂鸣器 | PB14 | 输出 | 低电平响 |
| 心跳指示灯 | PB15 | 输出 | 500ms 翻转一次 |
| OLED 屏 | PB8 = SCL，PB9 = SDA | 软件 I2C | 从机地址 0x78 |

**舵机接线**：3 线舵机只有 正（VCC）/ 负（GND）/ 信号（PWM），**没有位置反馈**，角度由 PWM 脉宽开环控制，接 PB10 / PB11 即可。

## 串口指令

| 指令 | 功能 |
|---|---|
| `T` | 急停：停所有执行器 + 锁定（手动升/降时则停 + 记位置 + 回等待，不锁定） |
| `G` | 恢复自动，回到等待状态 |
| `W` | 等待指令 |
| `N` | 没找到树 |
| `S` | 原地寻找树 |
| `U` | 接近树木（超声波测距） |
| `P` | 开始涂白准备 |
| `R` | 后退 |
| `B` | 后退提示音 |
| `A` | 手动升 |
| `X` | 手动降 |

其中 `W/N/S/U/P/R/B/A/X` 是摄像头 AI 流程发来的状态字符，只在自动模式下生效；`T`/`G` 是蓝牙手动控制，始终最高优先级。

## 编译

1. 用 Keil MDK 打开 `Project.uvprojx`。
2. 确认目标器件为 STM32F103C8（64KB Flash）。
3. 编译（Build），通过 ST-Link / J-Link 下载。

## 注意事项

- **PA13（SWDIO）/ PA14（SWCLK）保留给 SWD 下载调试**，不要接外设。
- 代码里用了 `GPIO_Remap_SWJ_JTAGDisable`（关闭 JTAG、保留 SWD），以释放 PB3/PB4 给超声波用；所以**只能用 SWD 下载**，不能用 JTAG。
- `lift_is_up` 由底端限位开关 + 上电找零重建：开机让升降往下走到压上开关，即确定底端，随后按行程时间推算位置；手动 `T` 停在顶端/底端也会更新它。
- **电池检测分压电阻**：上臂 100k 接电池正极、下臂 33k 接 GND、中点接 PA4。分压比 33/133，满量程对应 13.3V，欠压阈值 9.0V（3 串三元锂 3.0V/节）、恢复阈值 9.6V。若用磷酸铁锂（4S 满电 14.6V）或铅酸，需相应调整电阻和阈值。
- **欠压迟滞（防振荡）**：触发保护用 9.0V、恢复用 9.6V，中间留 0.6V 迟滞。因为电机一停、负载减小，电池电压会回弹——没有迟滞就会陷入"停 → 电压回升 → 又启动 → 又跌 → 再停"的反复抖动；恢复后按 `G` 重新开始。
- **看门狗调试**：IWDG 一旦启动只能靠复位关闭；调试时已用 `DBGMCU_IWDG_STOP` 冻结，否则断点一停就会被反复复位。被看门狗复位后，开机第 2/3 行会显示 `RST:Watchdog`。
- **通信超时**：`COMM_TIMEOUT_MS = 120000`（120 秒），需大于最长状态"接近树木"的 90 秒，避免误触发；按 AI 实际指令节奏可调。
