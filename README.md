# 涂白车（tree-whitewash-robot）

基于 STM32F103C8T6 的树木涂白小车。采用**非阻塞状态机**架构，摄像头/AI 视觉流程与蓝牙急停**共用一路串口 USART2**——无论正在执行什么动作，蓝牙一收到 `T` 就立即停止。

## 特性

- **非阻塞架构**：所有动作（舵机平滑运动、超声波测距、电机运行）都用 1ms 时间戳推进，不用 `Delay_ms` 死等，主循环始终能响应串口指令。
- **`T` 急停 / `G` 恢复**：`T` 拥有最高优先级，任何状态下立即停所有执行器并锁定；`G` 恢复自动。
- **舵机平滑运动**：三次 Hermite（smoothstep）缓起缓停，非阻塞推进。
- **超声波非阻塞测距**：触发后靠时间戳判断，带无回波超时处理。
- **升降位置软件跟踪**：手动升/降时按 `T` 提前停，按方向记录当前位置（顶端/底端）。

## 硬件平台

| 项目 | 参数 |
|---|---|
| MCU | STM32F103C8T6（LQFP48，64KB Flash，72MHz） |
| 开发环境 | Keil MDK（ARMCC） |
| 串口 | USART2，9600 波特率，8N1 |

## 接线表

| 外设 | 引脚 | 类型 | 说明 |
|---|---|---|---|
| 蓝牙 / 摄像头串口（USART2） | PA2 = TX，PA3 = RX | UART | AI 流程字符 + 蓝牙 `T`/`G` 共用一路 |
| 舵机 1（喷头臂） | PB10 | PWM（TIM2_CH3，全重映射） | 3 线舵机 0~180°，0.5~2.5ms |
| 舵机 2 | PB11 | PWM（TIM2_CH4，全重映射） | 3 线舵机 0~180° |
| 超声波 HC-SR04 | PB3 = Trig（出），PB4 = Echo（入） | GPIO + EXTI4 | 接近测距，需开 SWJ JTAG 关闭 |
| 驱动轮电机 1（左） | PB12/PB13 方向 + PA6 = PWM | 直流电机 | PA6 = TIM3_CH1 |
| 驱动轮电机 2（右） | PA8/PA9 方向 + PA7 = PWM | 直流电机 | PA7 = TIM3_CH2 |
| 升降电机 | PB5/PB6 方向 + PB0 = PWM | 直流电机 | PB0 = TIM3_CH3 |
| 水泵 | PA0 | 输出 | 高电平开水泵 |
| 蜂鸣器 | PB14 | 输出 | 低电平响 |
| 心跳指示灯 | PB15 | 输出 | 500ms 翻转一次 |
| OLED 屏 | PB8 = SCL，PB9 = SDA | 软件 I2C | 从机地址 0x78 |

**舵机接线**：3 线舵机只有 正（VCC）/ 负（GND）/ 信号（PWM），角度由 PWM 脉宽开环控制，接 PB10 / PB11 即可。

## 串口指令

| 指令 | 功能 |
|---|---|
| `T` | 急停：停所有执行器 + 锁定（手动升/降时则停 + 记位置 + 回等待，不锁定） |
| `G` | 恢复自动，回到等待状态 |
| `W` | 等待指令 |
| `N` | 没找到树 |
| `S` | 原地寻找树 |
| `U` | 接近树木（超声波测距） |
| `P` | 开始涂白准备 |
| `R` | 后退 |
| `B` | 后退提示音 |
| `A` | 手动升 |
| `X` | 手动降 |

其中 `W/N/S/U/P/R/B/A/X` 是摄像头 AI 流程发来的状态字符，只在自动模式下生效；`T`/`G` 是蓝牙手动控制，始终最高优先级。

## 编译

1. 用 Keil MDK 打开 `Project.uvprojx`。
2. 确认目标器件为 STM32F103C8（64KB Flash）。
3. 编译（Build），通过 ST-Link / J-Link 下载。

## 注意事项

- **PA13（SWDIO）/ PA14（SWCLK）保留给 SWD 下载调试**，不要接外设。
- 代码里用了 `GPIO_Remap_SWJ_JTAGDisable`（关闭 JTAG、保留 SWD），以释放 PB3/PB4 给超声波用；所以**只能用 SWD 下载**，不能用 JTAG。
- `lift_is_up` 软件标志开机默认假设升降在低位，首次涂白方向据此决定；手动 `T` 停在顶端/底端会更新它。
