# 涂白车（tree-whitewash-robot）

基于 STM32F103C8T6 的树木涂白小车，用 Keil MDK 开发，标准外设库。摄像头端的 AI 视觉流程通过 USART2 下发状态字符，蓝牙急停共用这一路串口。

引脚分配、机械行程、电池分压电阻都按实车标定，换车或换接线需要重新量。

## 功能

- 非阻塞状态机，所有动作由 1ms 时间戳推进，不用 `Delay_ms` 死等
- 舵机平滑运动，三次 Hermite 缓起缓停
- 超声波非阻塞测距，带无回波超时处理
- 升降底端限位开关 + 上电自动找零
- 电池电压检测与欠压保护，带迟滞防振荡
- 独立看门狗（IWDG），超时约 2.5s
- 串口通信超时保护，非等待状态 120 秒无指令自动停机
- 开机显示上次复位原因
- OLED 显示状态、模式、电压、距离，欠压或找零失败时全屏报警

## 硬件平台

| 项目 | 参数 |
|---|---|
| MCU | STM32F103C8T6（LQFP48，64KB Flash，72MHz） |
| 开发环境 | Keil MDK（ARMCC） |
| 串口 | USART2，9600 波特率，8N1 |

## 接线表

| 外设 | 引脚 | 类型 | 说明 |
|---|---|---|---|
| 蓝牙 / 摄像头串口（USART2） | PA2 = TX，PA3 = RX | UART | AI 流程字符 + 蓝牙 `T`/`G` 共用一路 |
| 舵机 1（喷头臂） | PB10 | PWM（TIM2_CH3，全重映射） | 3 线舵机 0~180°，0.5~2.5ms |
| 舵机 2 | PB11 | PWM（TIM2_CH4，全重映射） | 3 线舵机 0~180° |
| 超声波 HC-SR04 | PB3 = Trig（出），PB4 = Echo（入） | GPIO + EXTI4 | 接近测距，需开 SWJ JTAG 关闭 |
| 驱动轮电机 1（左） | PB12/PB13 方向 + PA6 = PWM | 直流电机 | PA6 = TIM3_CH1 |
| 驱动轮电机 2（右） | PA8/PA9 方向 + PA7 = PWM | 直流电机 | PA7 = TIM3_CH2 |
| 升降电机 | PB5/PB6 方向 + PB0 = PWM | 直流电机 | PB0 = TIM3_CH3 |
| 升降底端限位开关 | PB7 | 输入（内部上拉） | 一端接 PB7，一端接 GND，压下导通；上电自动找零 |
| 电池电压检测 | PA4 | ADC 输入（ADC_IN4） | 分压电阻 100k/33k，12V 锂电池（3S），欠压 9.0V 保护 |
| 水泵 | PA0 | 输出 | 高电平开水泵 |
| 蜂鸣器 | PB14 | 输出 | 低电平响 |
| 心跳指示灯 | PB15 | 输出 | 500ms 翻转一次 |
| OLED 屏 | PB8 = SCL，PB9 = SDA | 软件 I2C | 从机地址 0x78 |

舵机是三线接法，VCC、GND、信号，角度由 PWM 脉宽开环控制，接 PB10 / PB11。

## 串口指令

| 指令 | 功能 |
|---|---|
| `T` | 急停：停所有执行器 + 锁定（手动升/降时则停 + 记位置 + 回等待，不锁定） |
| `G` | 恢复自动，回到等待状态 |
| `W` | 等待指令 |
| `N` | 没找到树 |
| `S` | 原地寻找树 |
| `U` | 接近树木（超声波测距） |
| `P` | 开始涂白准备 |
| `R` | 后退 |
| `B` | 后退提示音 |
| `A` | 手动升 |
| `X` | 手动降 |

`W/N/S/U/P/R/B/A/X` 是摄像头 AI 流程发来的状态字符，只在自动模式下生效；`T`/`G` 是蓝牙手动控制，始终最高优先级。

## 编译

1. 用 Keil MDK 打开 `Project.uvprojx`。
2. 确认目标器件为 STM32F103C8（64KB Flash）。
3. 编译（Build），通过 ST-Link / J-Link 下载。
4. 需要发布固件时：Keil 菜单 Options for Target → Output 勾选「Create HEX File」，编译后 `.hex` 生成在 `Objects/` 目录。

## 上电动作

启动顺序在 [User/main.c](User/main.c)：先 `Self_Check_Routine()`，再 `Lift_FindHome()`。上电后不需要任何指令，机器自己会动约 15 秒：

| 阶段 | 动作 | 时长 |
|---|---|---|
| 自检 · 舵机 | 两个舵机依次摆到 0° → 90° → 160° | 约 2.1 s |
| 自检 · 左驱动轮 | 正转 → 反转 | 1.6 s |
| 自检 · 右驱动轮 | 正转 → 反转 | 1.6 s |
| 自检 · 升降 | 上升 → 停 → 下降 | 约 2.9 s |
| 自检 · 蜂鸣器 | 长鸣 | 3 s |
| **找零** | **升降自行向下走，直到压上底端限位开关** | 视行程而定 |

自检和找零期间按蓝牙 `T` 可以随时急停，`SelfTest_Wait()` 会轮询 USART2。没连蓝牙就只能等它跑完或直接断电。

## 注意事项

- 上电前把驱动轮架空，清空升降行程内的物体。自检会让左右轮正反转、升降上下走。
- 第一次调试先别接水泵。
- PA13（SWDIO）和 PA14（SWCLK）留给 SWD 下载调试，不要接外设。
- 代码里用了 `GPIO_Remap_SWJ_JTAGDisable`，关掉 JTAG 只保留 SWD，把 PB3/PB4 释放给超声波。所以只能用 SWD 下载。
- `lift_is_up` 是靠底端限位开关和上电找零重建出来的：开机让升降往下走到压上开关，底端就算确定，之后按行程时间推算位置。手动 `T` 停在顶端或底端时也会更新它。
- 电池检测分压电阻，上臂 100k 接电池正极、下臂 33k 接 GND、中点接 PA4。分压比 33/133，满量程对应 13.3V。**欠压阈值 9.0V**、**恢复阈值 9.6V**，按 3 串三元锂每节 3.0V 定的。用磷酸铁锂（4S 满电 14.6V）或铅酸要相应改电阻和阈值。
- 欠压保护带迟滞，触发 9.0V、恢复 9.6V，中间留 0.6V。电机一停负载就小，电池电压会回弹，没有这段迟滞会在"停 → 电压回升 → 又启动 → 又跌 → 再停"之间反复抖动。恢复后按 `G` 重新开始。
- 锂电池务必用带保护板的，配合配套充电器，严禁过充、过放、短路。欠压触发后停机锁定，OLED 显示 `LowBattery!`，充好电按蓝牙 `G` 恢复。
- IWDG 一旦启动只能靠复位关闭。调试时已经用 `DBGMCU_IWDG_STOP` 冻结，否则断点一停就会被反复复位。被看门狗复位过的话，开机第 2/3 行会显示 `RST:Watchdog`。
- `COMM_TIMEOUT_MS = 120000`，也就是 120 秒，这个值必须大于最长的"接近树木"状态 90 秒，否则会误触发。按 AI 实际发指令的节奏可以再调。
